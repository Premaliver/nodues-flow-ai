RESTful Web APIs for Seamless University ERP / LMS & Student Portal Integration

📥 OpenAPI 3.0 Spec (.json)

🚀 Overview & University Integration

Smart NoDues AI provides high-throughput, secure RESTful APIs designed for instant integration with University Enterprise Resource Planning (ERP) systems, Student Information Systems (SIS), and Learning Management Systems (LMS) such as SAP Higher Education, ERPNext, CollPoll, Academia ERP, and PowerCampus.

🔒 Protocol: HTTPS / TLS 1.3
🔑 Auth: JWT Bearer Tokens
⚡ Data Format: Application/JSON
🛡️ Security: HMAC-SHA256 Signed QR
POST /auth/login

Authenticate & Issue JWT Bearer Token

Authenticates students, staff, or administrators and returns a JWT access token for subsequent API calls.

Request Payload

{ "email": "student@rayatbahra.edu", "password": "SecurePass123!", "role": "student" }

Response (200 OK)

{ "success": true, "message": "Login successful", "data": { "access_token": "eyJhbGciOiJIUzI1NiIsInR...", "user": { "id": "u-123", "email": "student@rayatbahra.edu", "role": "student" } } }
POST /student/api/apply

Submit New No-Dues Application

Initiates sequential clearance workflow (Facilities -> HOD -> Accounts -> Examination).

Header

Authorization: Bearer <access_token>

Request Payload

{ "semester_id": "sem-uuid-6", "category": "hosteller", "selected_departments": ["hostel", "mess"], "hod_department_id": "dept-hod-civil" }
POST /<department>/api/process/<app_dept_id>

Process Department Clearance (Approve / Reject)

Executes clearance verification with official remarks and digital signature audit.

Request Payload

{ "action": "approved", "remarks": "No pending dues verified. Clearance granted." }
POST /examination/api/generate-admit-card/<application_id>

Generate HMAC-SHA256 Signed Admit Card PDF

Enforces strict verification check (all preceding departments must be approved) and generates scannable QR PDF.

GET /verify-admit-card/<card_number>

Public Scannable Admit Card Verification

Public verification endpoint used by examination invigilators and security scanners to instantly validate student authenticity.
